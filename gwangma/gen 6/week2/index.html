1. 문제 소개: 문제 상황

숫자 사이에 연산자 배치

Problem

주어진 숫자 사이에 연산자를 배치하고, 가능한 식의 최솟값과 최댓값 탐색

  • 연산자 종류: +, -, *
  • 각 연산자의 사용 횟수 고정
  • n개의 숫자 순서 변경 불가
  • 연산자 우선순위 없이 앞에서부터 차례대로 계산
문제 링크: Codetree 연산자 배치하기

2. 문제 소개: 예제로 이해하기

같은 숫자, 다른 배치, 다른 결과

Example
  • 숫자의 순서는 고정
  • 변하는 것은 숫자 사이의 연산자 순서
  • 곱셈 우선순위 미적용, 앞에서부터 계산
  • 모든 배치를 확인해야 최솟값과 최댓값 누락 방지

핵심 관찰

연산자 개수는 같아도 배치 순서에 따라 누적 계산값 변화

5. 사용한 이유

작은 탐색 공간과 단순한 상태

Why

Brute Force 가능

  • 연산자 최대 10개
  • 각 자리마다 최대 3가지 선택
  • 상한: 310 = 59,049
  • 대략 81 * 81 * 9 < 100 * 100 * 10
  • 100,000 미만, 1초 기준 충분
  • 연산자 사용 횟수 제한으로 실제 경우의 수는 더 적음
59,049 최악 상한도 충분히 작음

DFS / Backtracking 적합

  • 첫 번째 연산자부터 하나씩 대입하는 구조
  • 상태: 현재 계산값, 깊이, 남은 연산자 개수
  • 재귀 깊이 최대 10~11, 메모리 부담 작음
  • 문제의 계산 순서와 구현 흐름이 거의 동일
  • 구현하기 쉬운 방식이라는 판단
cur depth ops

6. 사용하지 않은 알고리즘과 이유

BFS와 DP를 선택하지 않은 이유

Alternatives

BFS

  • 연산자의 사용 가능 횟수 고정
  • 각 상태마다 연산자 사용 현황 관리 필요
  • 큐에 중간 상태 저장
  • 단순 계산으로도 100,000 * 10 정도의 상태 관리
  • 메모리 한도 안이지만 DFS 대비 이점 작음
  • 최단거리 문제가 아니라 BFS 장점 약함
중간 상태를 많이 들고 갈 이유가 약함

DP

  • 더 작은 문제와 관계식 필요
  • 누적 계산값과 남은 연산자 개수가 상태에 포함
  • 점화식과 상태 관리 복잡
  • 입력 크기가 작아 완전탐색이 더 빠르고 단순
  • 작은 입력에서는 빠르게 푸는 것이 더 중요하다는 판단
상태 압축보다 완전탐색이 단순

7. 설계 흐름

선택 → 감소 → 계산 → 재귀 → 복구

Design

상태 정의

cur 현재까지 계산값
depth 다음 숫자 위치
ops 남은 연산자 개수

종료 조건

depth == N이면 최솟값과 최댓값 갱신

1사용할 연산자 선택
2현재 값과 다음 숫자 계산
3남은 연산자 개수 감소
4다음 깊이로 재귀 호출
5연산자 개수 원상복구
6다른 연산자로 반복

8. 코드와 결과

작성 코드 전체와 채점 결과

Code
#include <iostream>
using namespace std;

int min_ans = 1 << 30;     // 최솟값 저장
int max_ans = -(1 << 30);  // 최댓값 저장
int N;                     // 배열의 길이
int ops[4];                // 연산자 (+,-,* 순으로)
int arr[12];               // 입력된 수열을 저장

/** cur: 현재까지 계산된 값   depth: 현재 탐색하는 깊이 */
void dfs(int cur, int depth) {
  /** 만약에 탐색이 끝났으면 정답 갱신 */
  if (depth == N) {
    min_ans = min(min_ans, cur);
    max_ans = max(max_ans, cur);
    return;
  }

  /** 다음 노드 탐색 */
  for (int i = 0; i < 3; i++) {
    /** 현재 선택한 연산자의
        남은 횟수가 없으면 넘어감 */
    if (ops[i] == 0) continue;

    ops[i]--;  // 사용했으므로 1 감소
                switch (i) {
      /** 덧셈 */
      case 0: {
        dfs(cur + arr[depth], depth + 1);
        break;
      }

      /** 뺄셈 */
      case 1: {
        dfs(cur - arr[depth], depth + 1);
        break;
      }

      /** 곱셈 */
      case 2: {
        dfs(cur * arr[depth], depth + 1);
        break;
      }
    }

    /** 재귀 호출이 끝나면
        사용한 연산자 원상 복구 */
    ops[i]++;
  }
}


int main() {
  /** 입력 처리 */
  cin >> N;
  for (int i = 0; i < N; i++) cin >> arr[i];
  for (int i = 0; i < 3; i++) cin >> ops[i];

  dfs(arr[0], 1);

  cout << min_ans << " " << max_ans << "\n";
  return 0;
}

Check
